# 4K Plus TV Player — Approved Product Direction

## Audience and priorities

Private Android-phone application for existing 4K Plus TV customers. User
comfort, reliable playback and simple support take priority over public growth,
advertising or payments.

## Access methods

1. Remote activation with an app-generated Device ID and Device Key. An admin
   assigns a playlist through the private dashboard.
2. Manual entry using either an M3U/M3U8 URL or an authorized provider login.
   Local M3U file import and payment/trial flows are excluded.

## Experience

- Arabic and English, with correct RTL/LTR behavior.
- System, branded light and branded dark themes.
- Full portrait and landscape support on every screen.
- Home sections: Live TV, Movies, Series, Continue Watching, Favorites,
  Recently Watched and Playlists.
- Live TV: categories, channel list, live preview, EPG when available.
- VOD: poster browsing, clear details, watch/resume, seasons and episode cards.
- Player: subtitles, audio, aspect ratio, screen lock, PiP, gestures, smart retry,
  external-player fallback, series autoplay and sleep timer.
- Parental control: PIN-protected categories/items/settings with hide or lock modes.
- Branded progressive loading, friendly errors and privacy-safe support reports.

## Dashboard

Private responsive web dashboard for customers, devices, playlist sources,
activations, expiry, app releases and audit history. Use Device ID—not the real
hardware MAC address. Remote playlist secrets stay server-side.
